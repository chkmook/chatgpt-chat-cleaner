ChatGPT 사이드바에서 선택한 대화를 일괄 삭제하거나 보관하는 Chrome 확장 프로그램입니다.

## 변경

- 실행 전에 선택한 제목 전체와 개수를 한 번 확인합니다.
- 취소·Esc는 요청을 보내지 않으며, 실행 후 확인창을 닫습니다.
- 처리 중에는 사이드바에서 진행 상황과 중지를 확인하고 메시지 입력·대화 이동을 계속할 수 있습니다.
- 확장 표시 이름과 배포 파일명을 ChatGPT Chat Cleaner로 통일했습니다.

## 설치·업데이트

1. 아래 첨부 파일 중 `chatgpt-chat-cleaner-0.4.0.zip`을 내려받아 압축을 풉니다.
2. `chrome://extensions`에서 개발자 모드를 켜고, 압축해제된 확장 프로그램 로드로 `manifest.json`이 있는 폴더를 선택합니다.
3. 기존 설치를 업데이트한다면 기존 폴더의 파일을 교체하고 확장과 ChatGPT 탭을 각각 새로고침합니다.

GitHub가 자동으로 제공하는 Source code ZIP 대신 위 이름의 확장 ZIP을 사용합니다. `SHA256SUMS`는 첨부 ZIP의 SHA-256 확인용입니다. Chrome 111 이상이 필요합니다.

## 확인 범위

자동 검사는 가짜 로그인·대화·응답을 사용합니다. 실제 계정의 삭제·보관은 NOT_RUN, 현재 ChatGPT 서버 호환성은 NOT_VERIFIED입니다. 비공개 웹 요청을 사용하므로 ChatGPT 변경에 영향을 받을 수 있습니다.

삭제는 복구할 수 없습니다. 전체 선택은 현재 불러온 일반 대화만 대상으로 하며, 오류나 결과 미확인 시 자동 재시도하지 않습니다.
