# ChatGPT Chat Cleaner

ChatGPT 사이드바에서 대화를 여러 개 선택해 한 번에 삭제하거나 보관하는 Chrome 확장 프로그램입니다.

[다운로드](https://github.com/chkmook/chatgpt-chat-cleaner/releases) · [변경 기록](CHANGELOG.md) · [개인정보 처리](PRIVACY.md)

## 기능

- 체크박스·대화 제목·키보드로 다중 선택, 전체 선택·해제
- 선택한 대화 일괄 삭제·보관
- 실행 전 선택 목록을 한 번 확인
- 사이드바에서 진행 상황 확인·중지, 처리 중에도 메시지 입력·대화 이동

## 설치

Chrome 111 이상에서 사용할 수 있습니다.

1. [Releases](https://github.com/chkmook/chatgpt-chat-cleaner/releases)에서 `chatgpt-chat-cleaner-0.4.0.zip`을 내려받고 압축을 풉니다.
2. Chrome 주소창에서 `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 압축을 푼 폴더 중 `manifest.json`이 있는 폴더를 선택합니다.
5. [ChatGPT](https://chatgpt.com)를 새로고침합니다.

소스에서 설치하려면 이 저장소의 `extension` 폴더를 선택합니다. npm 설치나 빌드는 필요하지 않습니다.

업데이트할 때는 기존 확장 폴더의 파일을 교체하고, 확장 관리 화면과 ChatGPT 탭을 **각각 새로고침**합니다. 같은 확장을 중복으로 설치하지 않습니다.

## 사용

1. ChatGPT 왼쪽 대화 목록에서 **선택**을 켭니다. 확장 아이콘으로도 켜고 끌 수 있습니다.
2. 정리할 대화의 체크박스나 제목을 누릅니다. Enter·Space 선택도 지원합니다.
3. **삭제** 또는 **보관**을 누릅니다.
4. 확인창에서 제목과 개수를 확인하고 실행합니다. 취소·Esc는 작업을 실행하지 않습니다.
5. 진행 상황은 사이드바에서 확인합니다. **중지**는 현재 요청이 끝난 뒤 다음 대화부터 멈춥니다.

**삭제한 대화는 복구할 수 없습니다.** 전체 선택은 현재 사이드바에 불러온 일반 대화만 대상으로 합니다. 프로젝트·보관함·계정 전체를 탐색하지 않습니다.

한 번에 최대 1,000개를 순서대로 처리합니다. 오류나 결과 미확인 시 중단하며 자동 재시도하지 않습니다. 탭을 닫거나 새로고침하면 남은 작업이 이어서 실행되지 않습니다.

## 개인정보와 호환성

기존 ChatGPT 로그인 세션을 사용합니다. 별도 API 키가 필요 없으며, 인증 토큰을 저장하거나 확장 메시지로 전달하지 않습니다. 대화 본문을 조회하지 않고 외부 서버로 데이터를 보내지 않습니다. 자세한 내용은 [개인정보 처리](PRIVACY.md)를 참고하세요.

ChatGPT의 비공개 웹 요청을 사용하므로 서비스 변경에 따라 수정이 필요할 수 있습니다. OpenAI의 공식 제품이 아닙니다. 실제 계정의 삭제·보관 처리는 아직 검증하지 않았으며, 확인 범위는 [검증 기록](VALIDATION.md)에 정리했습니다.

## 개발·배포

Node.js 18 이상과 `zip`·`unzip`이 필요합니다. 추가 npm 의존성은 없습니다.

```sh
npm run check
npm test
npm run package
```

생성 파일: `dist/chatgpt-chat-cleaner-0.4.0.zip`, `dist/SHA256SUMS`.

`v0.4.0` 태그를 GitHub에 푸시하면 검사 후 ZIP과 체크섬을 GitHub Release에 게시합니다. 첫 업로드와 다음 버전 배포 방법은 [배포 안내](docs/RELEASING.md), 데모·브라우저 검사는 [개발 안내](docs/DEVELOPMENT.md)를 참고하세요.
